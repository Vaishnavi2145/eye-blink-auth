AI-Based Eye-Blink Password Authentication System

An AI-based authentication system that uses eye-blinking patterns as a password mechanism to provide an alternative biometric authentication approach.

Project Overview

The system is designed to authenticate users using eye-blink-based interaction rather than relying only on conventional passwords.

It combines computer vision and machine learning techniques to capture and analyze eye-blinking behavior for user authentication.

Key Features
User registration and authentication
Eye-blink-based password authentication
Face-related biometric processing
User account management
Secure access to authenticated features
File management functionality

Project Structure

The project contains the application source code, database components, templates, static resources, and supporting files required to run the authentication system.

How It Works
A user registers with the system.
The application captures and processes the user's facial information.
Eye-blinking behavior is used as part of the authentication mechanism.
During login, the system validates the user's authentication input.
Successfully authenticated users can access protected application features.
Project Purpose

The project explores the use of computer vision and biometric interaction for authentication, with eye-blinking patterns serving as an additional authentication mechanism.
